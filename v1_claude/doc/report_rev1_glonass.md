# GNSS アナログフロントエンド (GPS L1 / Galileo E1 / GLONASS L1) — GF180MCU 設計提案

対象: Wafer.Space シャトル (GlobalFoundries GF180MCU, `gf180mcuD`, 3.3 V デバイス)
参照: MAX2769 相当の機能 (LNA を除く)
英語版: `doc/report_rev1_glonass_EN.md`
用途: 衛星軌道投入ロケット (Falcon 9 / H-IIA / H3 クラス) 搭載 GNSS 受信機

本書の数値は、特記のない限り xschem 回路図から生成したネットリストを ngspice-47 + GF180MCU 公式モデル (typical, 27 °C) で
シミュレーションした結果です。「推定」と書いたものは解析式・文献値ベースで、トランジスタシミュレーションではありません。

## 1. 結論 (提案アーキテクチャ)

| 項目 | 提案 | 主な理由 (シミュレーション結果) |
|---|---|---|
| LNA | **チップ内に持たない**。アクティブアンテナ (G ≥ 25 dB) + SAW を前提 | ミキサ直入力で NF ≈ 16 dB (推定) でも、外部利得 25 dB でシステム NF 劣化 ≈ 0.3 dB |
| LO 生成 | **内蔵リング VCO + 整数 N PLL (N = 96 固定, 16.368 MHz TCXO)** | 1.571 GHz を全 PVT (AVDD 3.3 V ±5 %) で 2 bit バンド切替によりカバー。ループ帯域 ≈ 1.1 MHz でリング VCO の位相雑音を抑圧し、積分位相誤差 ≈ 1.2° rms (相関損失 < 0.01 dB) |
| VCO 方式比較 | LC-VCO (外付け L) と外部 LO は不採用 | 外付け L/ボンディングワイヤは打ち上げ振動でインダクタンスが変動 (マイクロフォニクス) し LO に FM が乗る。リング VCO + 広帯域 PLL で性能は十分なので、外付け部品・振動リスクを増やす理由がない。外部 LO は追加シンセサイザと 90° 生成が必要 |
| 周波数プラン | LO = 1571.328 MHz。GPS/Galileo → IF **+4.092 MHz**、GLONASS (k = −7…+6) → IF **+26.7…+34.6 MHz** | GPS IF は MAX2769 と同一 (既存ソフトウェア受信機と互換)。分周比が 2⁵×3 なので TSPC プリスケーラだけで構成でき、1.57 GHz で奇数分周が不要 |
| IF / ADC | 複素 (I/Q) 低 IF、各 2 bit (sign/magnitude)、**fs = fLO/16 = 98.208 MS/s** | 3 システムを 1 チャネルで同時受信。IF 帯域 0.67–36.6 MHz、2 bit 量子化損失 0.5 dB (システム sim) |
| ドップラー対策 | IF 帯域に十分なマージン + ベースバンドで ±60 kHz 探索 / FLL 補助 PLL + **AFC DAC (VCTCXO 制御)** + 低 g 感度 TCXO | ロケット軌道で最大ドップラー ≈ ±41 kHz、変化率 ≈ 160 Hz/s (加速中は 5 g 相当で ≈ 260 Hz/s)。フロントエンド帯域に対しては 0.15 % の拡がりで問題なし。本質的な制約は (1) 捕捉探索範囲 (2) 追尾ループ動特性 (3) TCXO の振動 (g 感度) |

ブロック構成:

```
            ext. active antenna + SAW (G>=25 dB)
                         |
 RFP/RFN (100 ohm diff) -+--> [mixer_iq: Gilbert x2] --I--> [VGA1]-[SK LPF]-[VGA2]-[SK LPF]-[VGA3]-[VGA4] --> [adc2b] --> I_SIGN/I_MAG
                         |              ^          --Q--> (same if_chain)                                   --> [adc2b] --> Q_SIGN/Q_MAG
                         |              | LO I/Q (0/90/180/270)                                                   ^ FS 98.208 MHz
 REFIN 16.368 MHz --> [refbuf]-->[PFD]-[CP]-[LF]--VCTRL-->[vco_ring4 1571.328 MHz]--+--> [divbuf]-[/2/2/2/2]--FS--+--> CLKOUT
                                   ^                                                                  |
                                   +----------------------------FB 16.368 MHz----[/3]-[/2]------------+
 AFC[7:0] --> [afc_dac R-2R 8bit] --> AFCOUT (to VCTCXO Vc)          [bias_gen constant-gm]
```

## 2. 前提と周波数プラン

| 信号 | RF 帯域 (ドップラー込み) | IF (LO = 1571.328 MHz) |
|---|---|---|
| GPS L1 C/A | 1575.42 ± 1.023 MHz ± 0.05 | +3.02 … +5.17 MHz |
| Galileo E1 (BOC(1,1) 主ローブ) | 1575.42 ± 2.5 MHz ± 0.05 | +1.54 … +6.64 MHz |
| GLONASS L1OF (k = −7…+6) | 1598.06 … 1605.38 ± 0.511 MHz ± 0.05 | +26.17 … +34.61 MHz |

- 負の IF 側 (−36…0 MHz) はイメージ帯 (1535–1571 MHz) で、I/Q を複素で扱うことで除去します。IRR は I/Q 位相誤差で決まり、
  VCO の直交誤差 3°(sim) で ≈ 31 dB です。GNSS 信号は雑音以下で、イメージ帯の雑音も SAW で抑えられるため十分です。
  なお Inmarsat 下り (1525–1559 MHz) が一部イメージ帯にかかるので、SAW は 1560 MHz 以下を ≥ 30 dB 抑圧するものを推奨します。
- fs = 98.208 MS/s (複素) で、ナイキスト ±49.1 MHz。折り返し端 (98.2 − 34.6 = 63.6 MHz) で IF 応答は通過帯より −16 dB です。
- 出力データ: I/Q × (sign, mag) = 4 bit @ 98.208 MHz (LVCMOS 3.3 V) + CLKOUT。
  GPS/Galileo のみを使う場合は、FPGA 側で 1/6 デシメーション (16.368 MS/s) すれば MAX2769 と同じフォーマットになります。

## 3. ブロック設計とシミュレーション結果

すべて `xschem/*.sch` (トランジスタレベル、GF180 `nfet_03v3/pfet_03v3`、`ppolyf_u_1k`、MIM 2 fF/µm²) とテストベンチ `xschem/tb_*.sch` です。

### 3.1 バイアス (`bias_gen`, `tb_bias`)
定 gm (β マルチプライヤ) + スタートアップ。分配は低 Vov ダイオード (NMOS 16u/2u, PMOS 32u/2u で 50 µA)。

| 条件 | 単位電流 |
|---|---|
| 27 °C, 3.3 V | 50.8 µA |
| −40 / 85 / 125 °C | 28.6 / 77.7 / 97.8 µA |
| VDD 2.8 → 3.6 V | 49.9 → 51.3 µA (±1.5 %) |

定 gm なので gm·R (= アンプ利得) は温度で一定に保たれますが、電流そのものは温度で大きく変わります (後述の改善項目)。

### 3.2 ミキサ (`mixer_iq`, `tb_mixer`, `tb_mixer_zin`)
I/Q 二重平衡ギルバートセル。Gm 対 80u/0.28u、スイッチ 40u、テール 2 mA × 2、負荷 1.3 kΩ ∥ 1 pF、入力は 2 × 50 Ω 終端。

| 項目 | 結果 |
|---|---|
| 入力インピーダンス (差動) | 113 − j17 Ω @ 1.575 GHz (S11 ≈ −20 dB, 100 Ω 基準) |
| 変換利得 (差動電圧) | **15.0 dB** |
| I/Q 振幅差 / 位相差 (理想 LO) | 0.04 dB / 90.09° |
| 圧縮 | −9.5 dBm 入力で 0.3 dB (P1dB > −9 dBm) |
| NF (推定) | ≈ 16 dB (ギルバートセルの解析式。ngspice には PSS/PNOISE がないため) |

### 3.3 IF チェーン (`if_chain` = `vga` ×4 + `sk_lpf1/2`, `tb_if`)
各段 AC 結合 (HPF ≈ 0.3 MHz/段): GPS の IF が 4.092 MHz なので DC オフセットと 1/f 雑音を構造的に除去でき、DC オフセットキャンセルループは不要です。
SK LPF は PMOS ソースフォロワ (バルク = ソース) で、4 次 Butterworth (f0 = 40 MHz) に容量を数値最適化しました。

| ゲインコード (G1=G2=G3) | 4.092 MHz | 34.6 MHz | 63.6 MHz | −3 dB 帯域 |
|---|---|---|---|---|
| 00 | 19.4 dB | 17.0 dB | 3.1 dB | 0.68 – 36.6 MHz |
| 01 | 29.8 dB | 27.5 dB | 13.6 dB | 0.68 – 36.8 MHz |
| 10 | 41.1 dB | 38.9 dB | 25.4 dB | 0.67 – 37.4 MHz |
| 11 | 44.1 dB | 42.0 dB | 28.6 dB | 0.67 – 37.6 MHz |

- 段ごとに 2 bit (≈ 3/6/10/11 dB) を独立に設定できるので、64 通りで ≈ 3.5 dB ステップ、全体 19–44 dB の可変範囲です。
- 入力換算雑音 (4 MHz): 7.5 nV/√Hz (最大利得) – 26 nV/√Hz (最小利得)。ミキサ利得で割ると RF 換算 1.3 nV/√Hz で、ミキサ雑音に対して小さい値です。
- RF 入力 → ADC 入力の総利得は 34–59 dB です。ADC 閾値 ±0.157 V = 1σ にするための AGC 目標は、外部利得 25–40 dB に対応します。

### 3.4 2 bit ADC (`adc2b` = `sa_comp` ×3, `tb_adc`)
4 入力 StrongARM (信号対 + 参照対) で (v − Vth) を直接判定 → 分離インバータ → NOR SR ラッチ。MAG = (v > +Vth) OR (v < −Vth)。

| 項目 | 結果 (98.208 MS/s, ランプ入力) |
|---|---|
| SIGN 閾値 | +3.5 mV (ランプ 1 ステップ以内) |
| MAG 閾値 | −155 mV / +158 mV (設計 ±157 mV) |
| 消費 | 0.56 mA (閾値ラダー 0.5 mA を含む) |

当初の設計では SR ラッチ入力のミラー容量が状態に依存し、33 mV のヒステリシスが出ていました。分離インバータを挿入して解消済みです。

### 3.5 VCO (`vco_ring4`, `vco_cell`, `tb_vco`)
擬似差動インバータ 4 段リング + 弱いクロスカップルラッチ (45°/段 → 0°/90°/180°/270° を直接出力)。
VCTRL → NMOS V/I (ソース縮退) → PMOS ミラーでリング電源 VR を電流駆動。B1/B0 で粗調整電流 (+2×, +4×) を加算します。

| コーナー | 1571.328 MHz でのバンド / VCTRL | KVCO 付近 |
|---|---|---|
| TT 27 °C 3.3 V | B=00 / 1.94 V | 560 MHz/V |
| FF −40 °C 3.6 V | B=00 / 1.17 V | 1.1 GHz/V |
| SS 85 °C 3.135 V | B=11 / 2.38 V | 0.4 GHz/V |
| SS 85 °C 3.0 V | **カバー不可** (B=11 で最大 1.58 GHz @ 2.75 V) | — |

→ AVDD は **3.3 V ±5 %** (外部 LDO) で規定します。I/Q 直交誤差は TT で ≈ 3°、VCO + LO バッファ電流は ≈ 3.5 mA です。
バンドは起動時にキャリブレーションで選びます (VCTRL がウィンドウ内に入る最小のバンドをホストまたは簡単な FSM で選択)。

位相雑音: ngspice の過渡雑音 (トランジスタ熱雑音相当の電流源を各リングノードに注入) で周期ジッタから求めた値は
**−108 dBc/Hz @ 1 MHz** (f0 = 1.562 GHz、σT = 64 fs、1561 周期。数値ジッタの床 1.6 fs は差し引き済み) です。
解析式 (Hajimiri, +6 dB マージン) では −104 dBc/Hz なので、PLL バジェットには保守側の −104 dBc/Hz を使っています。
過渡雑音では 1/f 雑音 (近傍の 1/f³ 領域) を含まないので、PLL 帯域 (≈ 1 MHz) の内側は PLL が抑圧する前提です。

### 3.6 PLL (`pll_core` = `refbuf`, `pfd`/`dff_r`, `cp`, `loop_filter`, `divbuf`, `div96`; `tb_pfdcp`, `tb_div`, `tb_pll`)
- 分周器: AC 結合自己バイアスインバータで LO (0–VR) を 3.3 V 振幅に復元 → TSPC /2 × 4 (→ **FS = 98.208 MHz**) → /3 → /2 (→ FB 16.368 MHz)。
  - FS: TT 1571.328 MHz 入力で 98.204 MHz (計測窓の誤差内で LO/16)。2.0 GHz 入力でもプリスケーラは正常動作 (125.0 MHz) し、マージンは 27 % 以上あります。
  - FB: TT、SS/85 °C/3.135 V の両方で **16.368 MHz (/96)**。分周器の消費は 0.70 mA です。
  - 修正履歴: 当初は /3 段を負荷の重い FS ノード (ADC クロック) から駆動していたため、エッジが鈍って TSPC が誤動作し /2 になっていました。
    /3 段は軽負荷の内部ノード c16 で駆動し、FS は専用バッファから出す構成に変更して解決しています。
- PFD: 7474 型 6-NAND DFF × 2 + リセット遅延 (インバータ 4 段)。CP: 200 µA (DC で 203/204 µA)。
  - 位相比較特性 4.2 µA/ns (実効 Icp ≈ 250 µA、スイッチの電荷共有分を含む)。±0.1 ns までデッドゾーンなし。静的位相オフセット ≈ 0.3 ns。
- ループフィルタ (オンチップ): R = 5.2 kΩ、C1 = 119 pF、C2 = 9.8 pF。
- ループ解析 (`scripts/pll_design.py`、sim 値 Icp・KVCO を使用):

| コーナー | Icp | KVCO | fc | 位相余裕 |
|---|---|---|---|---|
| TT | 250 µA | 560 MHz/V | 1.09 MHz | 59° |
| FF −40 °C | 143 µA | 1.14 GHz/V | 1.24 MHz | 58° |
| SS 85 °C | 380 µA | 360 MHz/V | 1.07 MHz | 59° |

  定 gm バイアスの Icp の温度係数と、KVCO のコーナー依存が互いに打ち消し合い、帯域は 1.07–1.24 MHz に収まります。
- 位相雑音バジェット (`doc/pll_phase_noise.png`): 積分位相誤差 1.15° rms (1 kHz–50 MHz) → 相関損失 0.002 dB。
- トランジスタレベル閉ループ (`tb_pll`: バイアス + VCO + PLL 全体、VCTRL 初期値 1.7 V、`doc/pll_lock.png`):
  - リング起動直後の過渡を経て **約 2 µs でロック**。VCTRL = 1.935 V (tb_vco の 1.94 V と一致)、LO = 1.5714 GHz (計測窓の分解能内で 1571.328 MHz)。
  - 定常の REF–FB 位相差は −0.27 ns で、tb_pfdcp の CP 不整合によるオフセットと一致します。
  - VCTRL リップルから求めた基準スプリアス: **−47 dBc @ ±16.368 MHz** (2 次 −52 dBc)。
    GNSS 帯域内の強い干渉波がなければ相互混合の影響は無視できますが、改善項目に挙げています。

### 3.7 AFC DAC (`afc_dac`, `tb_afc`)
8 bit R-2R (R = 10 kΩ ポリ)。100 kΩ 負荷 (VCTCXO Vc) で 0–2.98 V、1 LSB = 11.7 mV、DNL 0.69 LSB、INL 0.35 LSB。
VCTCXO の引き込みが ±10 ppm / 2 V 程度なら 1 LSB ≈ 0.06 ppm ≈ 92 Hz (L1) です。

### 3.8 トップ (`gnss_afe_top`, `tb_top`)
トップ回路図のネットリストは xschem でエラーなく出力でき、全 28 サブセルの接続を確認済みです。
ただし、全チップ (約 820 トランジスタ (m 展開後)、リング発振器を含む) の DC 動作点は、ngspice で 25 分以内に収束しませんでした (KLU ソルバでも同じ)。
消費電流は、各ブロックのシミュレーション値の合算で見積もっています:

| ブロック | 電流 |
|---|---|
| VCO + LO バッファ | 3.7 mA |
| ミキサ I/Q | 4.0 mA |
| IF チェーン × 2 (VGA 4 段 + SK 2 段) | 24 mA |
| ADC × 2 | 1.1 mA |
| 分周器 + CP + 基準バッファ | 1.0 mA |
| CLKOUT (2 pF @ 98 MHz) + バイアス + AFC DAC | 1.2 mA |
| **合計** | **≈ 35 mA (≈ 115 mW @ 3.3 V)** |

消費の大部分は IF チェーンです (省電力は要求外なので、帯域と線形性を優先しています)。

## 4. ロケット搭載時のドップラー対策

### 4.1 ドップラー量 (`scripts/doppler.py`, `doc/doppler_profile.png`)
簡易打ち上げ軌道 (28.5°N 東向き、T+540 s で高度 200 km / 7.79 km/s、その後 LEO 慣性飛行) と Walker 星座モデルによる結果:

| システム | 最大ドップラー | 最大変化率 (モデル) |
|---|---|---|
| GPS L1 | ±38.4 kHz | 153 Hz/s |
| Galileo E1 | ±39.9 kHz | 154 Hz/s |
| GLONASS L1 | ±41.4 kHz | 160 Hz/s |
| TCXO ±2.5 ppm | ±3.9 kHz | — |

実機の最大加速度 (第 2 段燃焼終了直前で 4–5 g) を考えると、変化率は最大 ≈ 260 Hz/s、段間分離やエンジン停止の瞬間はジャーク (加加速度) が大きくなります。

### 4.2 フロントエンド側の対策 (本設計に実装済み)
1. **IF 帯域のマージン**: ±50 kHz のドップラーは IF 帯域 (0.67–36.6 MHz) に対して十分小さく、最も厳しい GLONASS k=+6 (34.61 MHz) でも通過帯内です (4 MHz 比 −2.4 dB)。
   Galileo E1 の BOC 下側ローブ (1.54 MHz) も HPF (0.67 MHz) より上にあります。単純に「帯域を広げる」ことよりも、**DC 近傍に信号を置かない低 IF プラン**のほうが効いています。
2. **AFC DAC (8 bit)**: ベースバンドが推定した受信機クロックドリフト (全衛星に共通の成分) で VCTCXO を引き込み、
   ドップラー探索窓の中心を補正します。衛星ごとのドップラーは打ち消せないため、これはベースバンド NCO で扱います。
3. **2 bit / 98 MS/s 出力**: ベースバンド側で任意の帯域・中心周波数のデジタルフィルタ/NCO を組めます (帯域拡張・システム別処理)。

### 4.3 ベースバンド側の必須対策 (提案)
- 捕捉: ドップラー探索 **±60 kHz** (500 Hz ビン、1 ms コヒーレント × 4 非コヒーレント)。
  `scripts/gnss_sysim.py` で、回路 sim の IF 特性 + 2 bit ADC を通した GPS (+38 kHz) と GLONASS k=+6 (−41 kHz) を 44 dB-Hz で捕捉でき、
  正しいビンでピーク/平均 12.7 / 13.2 dB でした (`doc/acquisition.png`)。
- 追尾: **FLL 補助 3 次 PLL** (FLL 帯域 ≈ 10 Hz、PLL 帯域 15–20 Hz)。3 次ループなら一定加速度 (一定ドップラー変化率) で定常誤差がゼロになります。
  ジャークの大きい段間分離時は FLL 単独に切り替え、DLL はキャリア補助付きにします。
- 慣性/軌道支援: 飛行計画軌道や IMU からドップラーとその変化率を予測して NCO に与えると、探索範囲を ±数 kHz に絞れて (再) 捕捉が速くなります。

### 4.4 振動 (g 感度) — フロントエンドの外で最も重要な点
TCXO の加速度感度 Γ により LO に位相変調がかかります。ピーク位相偏移 = Γ·a·f_L1 / f_vib (a = 10 g の場合):

| Γ | 20 Hz | 100 Hz | 500 Hz |
|---|---|---|---|
| 1 ppb/g (一般的な TCXO) | 45° | 9.0° | 1.8° |
| 0.1 ppb/g (低 g 品) | 4.5° | 0.9° | 0.18° |

PLL (帯域 1 MHz) はリファレンスの変調をそのまま LO に伝えるため、チップ内では除去できません。**低 g 感度 (≤ 0.1 ppb/g) の TCXO/OCXO と防振マウント**を推奨します。
同じ理由で、外付けインダクタの LC-VCO も振動でインダクタンスが変わり FM が乗るので、リング VCO を採用しました。

## 5. 外付け部品・ピン (案)

| ピン | 説明 |
|---|---|
| RFP, RFN | 差動 RF 入力 (100 Ω)。シングルエンドの場合はバラン、または RFN を AC 接地 |
| REFIN | 16.368 MHz TCXO/VCTCXO (クリップドサイン 0.8 Vpp、AC 結合) |
| AFCOUT | VCTCXO Vc へ |
| B0, B1 | VCO バンド |
| IG1A/B, IG2A/B, IG3A/B | IF ゲイン (I/Q 共通、AGC はベースバンドから) |
| AFC[7:0] | AFC DAC コード |
| I_SIGN, I_MAG, Q_SIGN, Q_MAG, CLKOUT | 2 bit I/Q データ + 98.208 MHz クロック |
| VCTRL | テスト用 (ループフィルタ観測) |
| VDD, VSS | 3.3 V ±5 % (実装時は RF/VCO/IF/デジタルで分離を推奨) |

制御ピン (B, G, AFC で 16 本) は、パッド数が厳しければ SPI レジスタ (標準セル) に置き換えます。

## 6. 未検証事項・リスク・次の作業

- **レイアウト未実施**: すべてプリレイアウトのシミュレーションです。LO 配線 (1.57 GHz、4 相) の寄生容量はリング周波数を直接下げるので、PEX 後に SS コーナーの周波数マージンを再確認する必要があります。
- **ミキサ NF / VCO 位相雑音**: ngspice に PSS/PNOISE がないため、それぞれ解析式と過渡雑音による見積もりです。Xyce の HB/Spectre RF などでの確認を推奨します。
- **Icp/バイアスの温度係数**: 定 gm バイアスは −40→125 °C で 3.4 倍変わります。ループ帯域は KVCO と打ち消し合って 1.07–1.24 MHz に収まっていますが、バンドギャップ基準の CP 電流に変える余地があります。
- **CP 不整合**: 静的位相オフセット 0.3 ns、基準スプリアス −47 dBc。ユニティゲインバッファ付き電流ステアリング CP で改善できます。
- **VCO ヘッドルーム**: AVDD 3.0 V の SS/85 °C では 1.571 GHz に届きません (3.135 V ならカバー)。マージンを増やすには LO バッファの負荷低減、または VCO 専用 LDO が必要です。
- **ESD/パッド**: RF 入力パッドの ESD 容量 (≈ 0.3–1 pF) で整合がずれるので、パッドライブラリが決まったら再整合します。
- **放射線**: LEO 投入までの短時間なら TID は問題になりませんが、SEL 対策 (ガードリング、電流制限) は実装時に考慮が必要です。
- **輸出規制**: 515 m/s・18 km を超えて動作する GNSS 受信機は COCOM/輸出管理の対象です。主にベースバンド/ファームウェア側の話ですが、事前に確認してください。

## 8. 確認させてください

1. **外部 RF 構成**: アクティブアンテナ/外付け LNA のゲインと SAW の帯域。本設計は G ≥ 25 dB、1560–1610 MHz 通過を前提にしています。
2. **ベースバンド**: 98.208 MHz × 4 bit の LVCMOS を FPGA で受けられるか。受けられない場合は、チップ内にデシメーションフィルタを入れるか、fs を 65.472 MHz (GLONASS を一部諦める) に下げる案があります。
3. **基準発振器**: 16.368 MHz VCTCXO で良いか (10 MHz 系が必須なら PLL 分周比を変更します)。g 感度のスペック。
4. **電源**: 3.3 V ±5 % (LDO) で良いか。
5. **パッケージ/パッド数**: Wafer.Space の I/O 数の制約。制御を SPI 化するかどうか。
6. **温度範囲**: −40…+85 °C で良いか。
7. **追加周波数帯**: 将来 L2/L5 (2 チャネル目) が必要か。
